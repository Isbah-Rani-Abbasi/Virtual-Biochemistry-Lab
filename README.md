# 🧪 Virtual Biochemistry Lab

An interactive, browser-based biochemistry learning platform designed to help students explore lab experiments, test their knowledge, and prepare for exams — all in one immersive virtual environment.

🔗 **Live Demo:** [Virtual Biochemistry Lab](https://isbah-rani-abbasi.github.io/Virtual-Biochemistry-Lab/)

## 📖 Overview

This project simulates a virtual biochemistry lab experience, combining educational content with interactive activities. It's built for students who want a hands-on, self-paced way to revise key concepts through experiments, puzzles, and numerical practice.

## ✨ Features

- **Virtual Experiments** – Explore simulated biochemistry lab experiments interactively
- **Crossword Puzzles** – Reinforce terminology and concepts through gameplay
- **Numerical Practice** – Solve biochemistry-related numerical problems
- **Study Resources** – Access curated books and additional reading material
- **Practice Material** – Extra exercises for exam preparation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/Isbah-Rani-Abbasi/Virtual-Biochemistry-Lab.git
   ```
2. Open `index.html` in your browser

No build steps or dependencies required — it's a static site.
